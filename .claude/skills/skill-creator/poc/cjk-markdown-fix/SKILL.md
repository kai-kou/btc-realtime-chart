# CJK Markdown 半角スペース修正

CJK（漢字・ひらがな・カタカナ等）本文中の **強調**（太字）記法の前後に半角スペースを入れてください（例:「これは重要です」→「これは **重要** です」）。この修正はインラインコード（`code`）には適用しません。

入力テキストを、このルールに従って修正してください。修正後の本文だけを出力してください（説明・前置き・コードフェンス不要）。
